# core

Слой singleton-инфраструктуры приложения: то, что создаётся один раз на всё приложение и не зависит от бизнес-фич.

## Что кладём

- `services/` — глобальные сервисы (`providedIn: 'root'`): HTTP-клиент, хранилище токенов, конфигурация.
- `interceptors/` — HTTP-интерсепторы (подстановка токена, единая обработка ошибок, логирование).
- `guards/` — route guards (`authGuard`, `guestGuard`, …).
- `models/` — по мере необходимости глобальные перечисления и типы, которым не место в `shared`.

## Правила слоя

- Только синглтон-сервисы и инфраструктура, без presentational-компонентов.
- Разрешено импортировать из `shared` и внешних пакетов.
- Запрещено импортировать из `features` и `layouts`.
- Всё в папке — standalone (Angular 19, без NgModules).
