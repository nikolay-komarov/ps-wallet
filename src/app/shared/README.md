# shared

Слой переиспользуемых «глупых» (presentational) артефактов без бизнес-логики.

## Что кладём

- `components/` — UI-компоненты (кнопки, инпуты, карточки, модалки). Только `@Input` / `@Output` / content projection, без знаний о фичах.
- `directives/` — переиспользуемые структурные и атрибутные директивы.
- `pipes/` — переиспользуемые пайпы (форматирование дат, валют и т. п.).
- `models/` — общие типы, интерфейсы и перечисления приложения.

## Правила слоя

- Компоненты только декларативные: данные приходят через `@Input`, события — через `@Output`.
- Разрешено импортировать только из внешних пакетов.
- Запрещено импортировать из `core`, `features` и `layouts`.
- Всё в папке — standalone (Angular 19, без NgModules).
