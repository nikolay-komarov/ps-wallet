# features

Слой бизнес-доменов приложения (авторизация, операции, категории, бюджеты…). Каждая фича — отдельная папка с ленивой загрузкой.

## Шаблон фичи (пример — `auth`)

```
features/auth/
├── auth.routes.ts          # маршруты фичи (ленивая загрузка из app.routes.ts)
├── pages/                  # страницы фичи (login-page, register-page)
├── components/             # компоненты, специфичные только для этой фичи
├── services/               # сервисы фичи (AuthApiService и т. п.)
└── models/                 # типы и интерфейсы фичи
```

## Правила слоя

- Фича не знает о других фичах (изоляция): общий обмен — только через `core` и `shared`.
- Разрешено импортировать из `core` и `shared`.
- Запрещено импортировать из `layouts` и из других `features`.
- Маршруты фичи регистрируются лениво из `app.routes.ts`.
- Всё в папке — standalone (Angular 19, без NgModules).
