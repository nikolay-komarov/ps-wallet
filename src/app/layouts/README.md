# layouts

Каркасы (shell) страниц: общая рамка, в которую встраивается содержимое маршрутов.

## Что кладём

- `main-layout/` — каркас основного приложения (шапка, боковое меню, `router-outlet`, подвал).
- (по мере необходимости) `auth-layout/` — отдельный каркас для экранов входа и регистрации.

## Правила слоя

- Без бизнес-логики: используют `router-outlet` и компоненты из `shared`.
- Разрешено импортировать из `shared`.
- Запрещено импортировать из `core` и `features`.
- Всё в папке — standalone (Angular 19, без NgModules).
